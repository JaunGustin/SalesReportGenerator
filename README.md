# SalesReportGenerator

Java program that generates and processes sales data (salesmen, products, and sales), producing sorted revenue and product reports.

Developed for the **Fundamentals of Programming** module — Politécnico Grancolombiano.

## Status

**Delivery 1** — done. Includes `GenerateInfoFiles`, which generates the sample input files.

## Requirements

- Java 8
- Eclipse IDE for Java Developers

## How to run

1. Import as an existing Java project in Eclipse.
2. Run `GenerateInfoFiles.java` as a Java Application.
3. Check the console for a success/error message.
4. Refresh (F5) to see the generated `.txt` files in the project root.
